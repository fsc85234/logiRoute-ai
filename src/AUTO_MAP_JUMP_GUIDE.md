# ✨ 掃描後自動跳轉至地圖功能

## 改動說明

**只改了 1 行代碼！**

### 原本流程 ❌
```
掃描地址 → 點導入 → 跳到「地址庫」 → 手動切換到「地圖」 → 才看得到地址
```

### 新流程 ✅
```
掃描地址 → 點導入 → 自動跳到「地圖」 → 立即看到地址（自動地理編碼）
```


## 流程說明

### 用戶操作
1. 在「智慧辨識」頁面上傳發票
2. OCR 掃描完成，顯示提取的地址
3. 點擊「導入」按鈕
4. ✨ **自動跳到「地圖」頁面**
5. 地圖自動觸發地理編碼（GPS 座標查詢）
6. 約 5-10 秒後，所有配送點出現在地圖上

## 🔧 進階自定

如果你想要導入後停留在「地址庫」，改回：
```javascript
setActiveTab('database');
```

或者想要導入後停留在「設定」（不推薦）：
```javascript
setActiveTab('settings');
```

## ❓ 常見問題

**Q：導入後地圖一直在「正在獲取 GPS 座標」？**  
A：這是正常的。OSM Nominatim 服務需要 5-15 秒來查詢每個地址的座標，稍等一下就會出現。

**Q：想要導入後回到掃描頁面重新上傳？**  
A：改成 `setActiveTab('ocr')` 即可。

**Q：導入後能否自動選定新導入的日期？**  
A：可以，但需要額外改動。在 `RoutePlanner` 中加入自動選日期邏輯。需要幫忙嗎？
